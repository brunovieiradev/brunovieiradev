## 🚀 Projeto em destaque

### NEXUS — Plataforma de aprendizagem

O **NEXUS** é um projeto em desenvolvimento que busca reunir organização de estudos, acompanhamento de progresso e ferramentas de apoio à aprendizagem.

**Tecnologias utilizadas:**
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
